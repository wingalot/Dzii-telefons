# 2026-03-31 - Felix Trading System Fixes

## Critical Fixes Implemented

### 1. Duplicate Signal Detection
- **Problem**: Signals were being executed twice (e.g., EUR/AUD opened 2 positions 1 min apart)
- **Solution**: Added 5-minute duplicate detection window in Signal Hub
- **File**: `felix_signal_hub.py` - `register_signal()` method

### 2. Shared State Module
- **Created**: `shared_state.py` for centralized state management
- **Purpose**: All components (Signal Hub, TP Manager, AI Supervisor) now share state
- **Tracks**: Active signals, IG positions, pending orders, orphan positions
- **Location**: `~/.openclaw/ai_supervisor/state/shared_state.json`

### 3. Missing Epic Codes
- **Added**: USDCHF, EURAUD, CHFJPY, AUDJPY, CADJPY, NZDJPY, EURCAD, GBPAUD, GBPCAD
- **File**: `felix_tp_manager.py` - `epic_to_pair()` method

### 4. AI Supervisor Position Monitoring
- **New Function**: `monitor_open_positions()` - runs every 2.5 minutes
- **Purpose**: Detects positions missing TP/SL and attempts recovery
- **Recovery**: Searches trade history, waits 2 min for update signal, alerts user if fails
- **Files**: `felix_ai_supervisor.py`

### 5. Telegram Notifications
- **Created**: `send_notification.py` for Telegram Saved Messages
- **Triggers**:
  - New order executed (with full details)
  - Position closed (with P/L calculation)
  - Partial close at TP2 (50%)
  - Unknown/orphan positions detected

### 6. TP Manager Enhancements
- **Added**: `check_unknown_positions()` - detects positions not from Felix signals
- **Added**: `sync_with_shared_state()` - keeps shared state in sync
- **Added**: Notifications for all close events (SL, TP3, Fallback)

### 7. LIMIT Order Fixes
- **Problem**: LIMIT orders were executing as MARKET orders
- **Solution**: Fixed parameter order in `felix_trader.sh`
  - Old: `order "$epic" "$direction" "$min_size" "" "" "$currency_code"`
  - New: `order "$epic" "$direction" "$min_size" "" "" "LIMIT" "$entry"`

### 8. ACTIVATED Message Handling
- **Added**: TP Manager now handles "LIMIT ACTIVATED" messages from Signal Hub
- **Purpose**: When limit order fills, properly registers position for TP/SL tracking

## Current System Architecture

```
Felix VIP Room (Telegram)
    ↓
Signal Hub - Detects duplicates, registers signals
    ↓
AI Supervisor - Executes, monitors, fixes errors
    ↓
IG API - Opens/closes positions
    ↓
TP Manager - Monitors TP/SL, manages exits
    ↓
Telegram Notifications (Saved Messages)
```
