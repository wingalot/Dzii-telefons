## AI Supervisor Fixes

### 1. Pre-parsed Data Usage
**Problem:** AI Supervisor was failing to parse signals when Signal Hub already parsed them.
**Solution:** Modified `felix_ai_supervisor.py` to use `extracted_data` from Signal Hub instead of re-parsing.
**Code change:** Check for `extracted_data` in signal and use it directly if valid.

### 2. NZD Currency Support
**Problem:** EURNZD trades rejected with "UNKNOWN" error because NZD currency code was missing.
**Solution:** Added `*NZD)` case to currency detection in `ig_api.sh`.
**File:** `~/.trading/ig_api.sh`

### 3. Position Already Exists Handling
**Problem:** AI Supervisor kept retrying signals for pairs with existing positions, causing crashes.
**Solution:** Modified to mark signals as processed with status `position_already_exists_skipped` when duplicate detected.

### 4. TP Manager Price Check Fix
**Problem:** TP Manager was using non-existent 'price' command in ig_api.sh.
**Solution:** Changed to use 'market' command and parse snapshot data.
**Code:** Changed `price_data.get('bid')` to `snapshot.get('bid')`.
